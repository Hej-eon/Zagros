# Zagros — Bomb Arena

An original browser game inspired by the classic grid-based bomb arena genre.

## Prototype 0.1
- Grid movement
- Timed bombs and directional explosions
- Destructible blocks
- Chain reactions
- Enemies
- Range and bomb power-ups
- Score, lives and timer
- Keyboard and mobile controls
- Responsive canvas UI

## Controls
WASD / Arrow keys = move. Space = bomb.

## Run
Open index.html in a browser. No build step is required.
